## 2. YouTube per-lesson video scraper + Coursera references

**Goal:** Upgrade the 3 tracks from a single shared video per course to a unique, relevant YouTube video per lesson (scraped automatically), plus attach free Coursera course links/metadata as references.

**YouTube scraper — `backend/src/seed-scrape-course-videos.ts` (new):**
- For each of the 169 lessons in the 3 tracks, searches YouTube via `yt-dlp "ytsearch5:course module lesson tutorial"` and ranks the top 5 by: duration (2–60 min band, 10–30 min ideal), trusted education channels (freeCodeCamp, Bro Code, Mosh, Traversy, IBM, Simplilearn…), title-term overlap with the lesson name, and view count; penalizes "…in 5 minutes" clip intros.
- Stores only `lessons.video_url` (`https://youtube.com/watch?v=<id>`) — nothing downloaded/re-hosted.
- Flags: `--dry-run`, `--limit N`, `--only-missing`, `--resume`, `--reprocess-dupes` (re-searches lessons pinned to an over-used video ≥3× and demotes repeat winners). Progress checkpoint in `yt_scrape_progress.json`.
- npm scripts: `seed:yt:scrape`, `seed:yt:scrape:dry`.
- Installed standalone `yt-dlp 2026.08.19` to `backend/tools/` (python unavailable; gitignored). Resolved via `YTDLP_BIN` env → `backend/tools/yt-dlp.exe` → PATH.

**Result:** 169/169 lessons got a unique URL; de-duplicated pass reduced every ≥3× repeat down to max 2×, with better per-topic picks (e.g., TestNG assertions, CSS Box Model, Flexbox-vs-Grid).
